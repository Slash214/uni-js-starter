# 架构决策记录（ADR）

在此目录用 `0001-标题.md` 递增编号记录**不可逆或高成本**的架构选择（技术栈、鉴权方案、状态边界等）。

新建 ADR 时可从以下骨架粘贴：

```markdown
# ADR-000N：标题

## 状态

提议 | 已采纳 | 已废弃

## 背景

## 决策

## 后果

```

与 [mattpocock/skills](https://github.com/mattpocock/skills) 中的 `improve-codebase-architecture`、`diagnose` 等技能配合：改动前阅读相关 ADR，避免与历史决策冲突。
